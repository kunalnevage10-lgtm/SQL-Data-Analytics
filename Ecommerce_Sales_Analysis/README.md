# 🛒 E-Commerce Sales Analysis with BigQuery

This directory contains production-ready SQL scripts targeting the Google BigQuery public e-commerce clickstream dataset (`data-to-insights.ecommerce.all_sessions`).

## 📄 Contents
- **`ecommerce_queries.sql`**: Complete suite of analytical queries covering:
  - Top 10 Revenue-Generating Cities
  - Top Selling SKUs by Physical Unit Quantity
  - Acquisition Channel Breakdown (Transactions, Revenue, Conversion %)
  - Pageview and Cart Progression Metrics

For full setup and usage instructions, refer to the [Root README](../README.md).
